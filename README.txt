PrimeSpace static frontend

Pages:
- index.html
- venues.html
- venue.html?id=executive-conference-center
- login.html
- provider-login.html
- register.html
- providers.html

How to use:
1. Keep the folder structure unchanged.
2. Open index.html in a browser.
3. All pages are linked together with relative links.

Notes:
- The site uses only HTML, CSS, and JavaScript.
- Venue cards and venue detail content are populated from assets/js/data.js.
- Booking total on venue.html updates when the guest count changes.
